## Styling and UI components

| Package                    | License    | Purpose                                                                                                         |
| -------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------- |
| `tailwindcss`              | MIT        | Utility-first CSS, the styling approach mandated for this project                                               |
| `shadcn` (CLI)             | MIT        | Generates component source directly into the repo; a build-time tool, not a runtime dependency                  |
| `@base-ui/react`           | MIT        | Unstyled, accessible component primitives (dialogs, popovers, menus) that shadcn/ui's generated components wrap |
| `class-variance-authority` | Apache-2.0 | Typed variant styling for components generated by shadcn/ui                                                     |
| `clsx`, `tailwind-merge`   | MIT        | Conditional and conflict-safe Tailwind class composition                                                        |
| `lucide-react`             | ISC        | Icon set used by shadcn/ui's generated components                                                               |
| `tw-animate-css`           | MIT        | Tailwind-native animation utilities used by shadcn/ui's generated components                                    |

**Why shadcn/ui**: it was chosen over alternatives such as MUI, Chakra, or Mantine because it fits the mandated Next.js + Tailwind stack directly rather than bringing its own styling system, and because it's a code generator, not an installed component library: components are copied into `src/components/ui` and become part of this codebase, so there's no version lock-in or opaque runtime dependency to work around, and every component can be edited freely. It sits on top of `@base-ui/react` for accessibility (keyboard navigation, focus management, ARIA), which is the same accessibility foundation Radix UI (its predecessor default) provides.
